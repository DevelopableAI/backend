# Developable

Generate production-hardened Express + TypeScript REST APIs from a Prisma schema — with security invariants baked in by default.

Use it as a **Claude Code skill** (`/developable`), a **Codex skill**, or a **Python CLI**.

---

## Install (Claude Code)

```bash
curl -sSL https://raw.githubusercontent.com/developableai/backend/main/install.sh | bash
```

Restart Claude Code, then:

```
/developable
```

The skill walks you through schema input (or plain-English description), generates the full API, and writes the files directly into your project. No Python runtime needed for skill-only use.

$skill-installer install https://github.com/developableai/backend/tree/main/skills/developable

## What gets generated

Given a `schema.prisma`, Developable outputs a complete Express + TypeScript REST API:

- Routes → controllers → repositories (one file per concern)
- JWT auth middleware wired on all write routes
- Zod validators generated by Claude, tailored to your fields
- Ownership checks before every update and delete
- Sensitive fields hashed and scrubbed from all responses
- Paginated, filterable, sortable list endpoints
- One-to-many nested routes (`GET /users/:id/posts`)
- Docker, docker-compose, GitHub Actions CI
- Python integration test suite (100+ cases per entity)

**Security invariants are structural** — they are in the Jinja2 templates, not prompts. They cannot be skipped.

## Schema annotations

```prisma
// @auth_entity
// @llm Users can only access their own posts
model User {
  id       Int    @id @default(autoincrement())
  email    String @unique
  password String // @llm sensitive
  posts    Post[]
}

model Post {
  id       Int    @id @default(autoincrement())
  title    String
  content  String
  author   User   @relation(fields: [authorId], references: [id])
  authorId Int
}
```

| Annotation | Effect |
|---|---|
| `// @auth_entity` | Marks the login principal; triggers auth controller + JWT middleware |
| `// @llm sensitive` | Field is hashed at rest, excluded from JWT and all API responses |
| `// @llm <hint>` | Free-text hint forwarded to Claude when generating validators for this entity |

## Security invariants

Every generated API enforces these unconditionally:

| Invariant | Enforced in |
|---|---|
| Integer ID validation — rejects floats, alpha, SQL injection suffixes, overflow | `_parseId` in controller |
| String ID validation — rejects whitespace, oversized strings (for `uuid()`/`cuid()` PKs) | `_parseStringId` in controller |
| Owner FK injected server-side from JWT, never accepted from request body | controller create + validator LLM hint |
| Auth entity self-ownership: users may only update/delete their own record | controller `is_auth_entity` branch |
| Resource ownership check before any update/delete on owned resources | controller `owner_fk_field` branch |
| Sensitive fields hashed with bcrypt before storage | auth controller |
| Sensitive fields excluded from JWT payload and all API responses | auth controller `safeSelect` |
| JWT verified on all write and ownership-sensitive read routes | routes + auth middleware |
| Filter fields validated against allowlist — sensitive and unknown fields rejected (400) | controller `ALLOWED_FILTER_FIELDS` |

## REST endpoints

Every entity gets:

| Method | Path | Auth |
|---|---|---|
| `GET` | `/api/{plural}` | Optional |
| `GET` | `/api/{plural}/:id` | Optional |
| `POST` | `/api/{plural}` | Required |
| `PUT` | `/api/{plural}/:id` | Required |
| `DELETE` | `/api/{plural}/:id` | Required |

Filter and sort on all list endpoints:

```
GET /api/posts?filter[title]=hello&sort=createdAt&order=asc&page=1&limit=20
```

One-to-many relations generate nested routes automatically:

```
GET  /api/users/:id/posts
POST /api/users/:id/posts
```

## Python CLI (advanced)

The CLI is for batch generation, GitHub publishing, and cloud deployment. The Claude Code and Codex skills do not require it.

**Install:**

```bash
pip install developable
export ANTHROPIC_API_KEY=sk-ant-...
```

**Generate:**

```bash
developable schema.prisma --out ./my-api
```

**Common flags:**

```
--no-llm          Skip Claude API calls (placeholder Zod schemas, instant output)
--force           Overwrite user-modified files
--tests-out DIR   Generate Python integration test suite
--github          Init git, create GitHub repo, push
--rules FILE      Path to schema.rules.yaml with business rule constraints
```

**Deploy:**

```bash
python deploy.py --out ./my-api --deploy-to aws
python deploy.py --out ./my-api --deploy-to gcp --gcp-project my-project-id
python deploy.py --out ./my-api --deploy-to heroku
```

**After generation (no `--github`):**

```bash
cd my-api
npm install
npx prisma migrate dev --name init
npm run dev
# → http://localhost:3000
```

## Starting from a plain-English description

You don't need a schema to start. In Claude Code:

```
/developable "A task management app with users, projects, and tasks. Users log in with email and password."
```

The skill generates a `schema.prisma` with correct annotations and a `rules.yaml` with entity constraints, shows them to you for review, and generates the full API once you confirm.
